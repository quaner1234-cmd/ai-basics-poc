# AI会伤害人吗？ — Product Requirements

One line: 一个暗色、科技感的单页，用真实可查的 Darren Zhou 案，回答「AI遇上暴力时干了什么」，让人自己判断 AI 会伤害人吗。
Source: `scope.md > The Unique Kernel` / `The Core Loop` / `What "Working" Looks Like` / `The POC Boundary`。

## The Core Journey
1. 打开 `index.html`，第一眼是主标题 **「AI会伤害人吗？」**，副题引导 **「帮凶？帮手？AI遇上暴力，会怎么做？」**。
2. 页面邀请你点开/向下进入核心内容：**AI 干了什么**。
3. 最先看到的是**可滚动时间线**：从骚扰升级到计划成型、再到 OpenAI 紧急披露与逮捕——重点是**行动顺序和具体计划**被提取出来（目标、方式、地点、步骤、升级轨迹）。
4. 时间线传达 **AI 角色**：在这起案子里 AI 是**识别并上报**（帮手/拦截），不是帮凶。
5. 读到关键事实后，**来源可点、可核对**（三联报道等）。
6. 离开时带走自己的判断：关于「AI会伤害人吗」的一个更具体的答案。成立的瞬间是「这页面像件作品，而且事实站得住」。

## Screens and Layout
**一个页面（单页）**，竖向滚动即可走完；不要求多路由。

- **第一屏（Hero）**：主标题「AI会伤害人吗？」+ 副题「帮凶？帮手？AI遇上暴力，会怎么做？」+ 进入交互（按钮或向下滚动）。
- **第二屏（AI干了什么）**：可滚动时间线为骨架，突出「行动顺序 + 具体计划」；AI 角色标签（如：识别 / 上报）随段落出现。
- **第三屏（证据与来源）**：事实要点 + 可点击来源链接。
- **尾部（可选短结）**：留给「你怎么看」的一句收束或问题回声，不做社区/评论。

## Look and Feel
- **气质**：科技感，偏《黑客帝国》方向——暗底、终端/系统/档案/拦截感，高对比，信息密度可以高。
- **明确避免**：满屏绿色数字雨的俗套；通用 AI 落地页的紫蓝渐变；「点下一步看文章」的阅读感。
- **字体性格**：等宽字或具有终端/系统感的无衬线，标题要有压迫感/提问感。
- **颜色**：暗背景 + 少量高亮强调（具体色值在 `4-spec` 定）。
- **排版**：时间线要清晰可扫；「具体计划」信息块要一眼能读出结构。

## Features and Behavior

### 第一屏提问
- 显示主标题与副题；提供明确的「进入/点开」动作（或显著的滚动引导）。
- 验收：打开页面 3 秒内能看到「AI会伤害人吗？」与「帮凶？帮手？」的张力；存在可感知的下一步动作。

### AI干了什么 · 时间线
- 可滚动时间线呈现 Darren 案关键节点，**优先呈现行动顺序与具体计划**（计划中的目标、方式、地点、步骤、升级）。
- 每个节点/段落可标注 **AI 角色**（例如：识别风险言论 → 紧急披露执法部门）。
- 验收：不读长文也能回答「AI 在这案子里干了什么」；时间线可滚动走完；「具体计划」有结构化呈现（步骤/顺序可辨认）。

### 事实与来源
- 关键事实旁边或汇总区提供**真实来源链接**（至少：三联生活周刊该篇报道；能核对）。
- 验收：来源可点击（或完整展示可复制 URL）；正文主张与来源能对上。

### 交互与完成度
- 页面完整可用可交互（scope 的工程「done」）；交互包括：进入/展开、滚动时间线；允许小的展开收起，不做复杂控件。
- 验收：本地打开 `index.html` 即可演示；无空白壳、无断链主路径。

## States and Boundaries
- **首次打开** — 直接进入 Hero；无需配置、无需网络也能看核心结构（来源外链除外）。
- **来源链接失效（若发生）** — 显示完整出处文本（媒体名/标题/日期），不伪装可点。
- **内容边界** — 案件事实以报道为准；不编造细节；不确定处不写死。
- **无持久化** — 不登录、不存数据；刷新即回初始。

## Product Decisions
- 主标题定为「**AI会伤害人吗？**」；「帮凶？帮手？AI遇上暴力，会怎么做？」作副题/引导语。
- 核心叙事物是**可滚动时间线**，且第一优先是「行动顺序和具体计划」，不是人物小传或文学描写。
- 视觉走**暗色科技/终端档案感**（黑客帝国气质），避开绿色数字雨俗套。
- 案例锁定 **Darren Zhou 案（OpenAI 上报谋杀计划）**；一条做深做实，数量让位质量。
- 「识别暴力 / 具体性」是报道中的法律与技术看点，吸收进页面信息结构（计划的具体性），不另做法律科普长文。

## What We're Building
- 一个 `index.html`（+css/js）单页；
- Hero：「AI会伤害人吗？」+「帮凶？帮手？…」+ 进入动作；
- Darren 案可滚动时间线：行动顺序 + 具体计划提取 + AI 角色标注；
- 真实来源引用（可核对）；
- 有辨识度的暗色科技视觉系统；
- 完整、可用、可交互。

## Deferred From the POC
- 多案例库 / 完整时间线（最早→最近）— 收集核实成本过高。
- 「AI犯罪离我们有多远」自测互动 — 有价值，但是另一圈。
- 未来走向/预测一节 — 需要更多调研与表述分寸。
- 小说《会话已恢复》互文专区 — 个人素材，可后置。
- 后端、账户、评论、持续更新 — 与 PoC 无关。

## Possible Later Enhancements
- 加入巴西案、加拿大案作对照（帮手 vs 识别失败）。
- 「计划具体性」的可视化小图（要素强度）。
- 英文版或双语切换。

## Non-Goals
- 不做「AI 犯罪新闻聚合站」或搜索引擎。
- 不做游戏化叙事（点下一步）；不做互动小说。
- 不做法律意见/心理诊断；不鼓励暴力；不展示可模仿的可操作犯罪教学。
- 不使用无授权的全文转载作为主内容；引用以短摘+出处为主。

## Open Questions
- 时间线节点的最终文案与时间点（以报道为准整理）— 可在 `4-spec`/构建时整理，不阻塞 PRD 通过。
- 具体色值/字体文件选型 — 属 `4-spec`。
- 来源数量下限：1 条核心报道是否足够，或补充 OpenAI 公开声明链接 — 倾向「≥1 条可核报道，能加则加」，不阻塞。
